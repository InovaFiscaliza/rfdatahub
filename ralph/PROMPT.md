# Ralph loop — Full (ungrouped) station pipeline

You are one iteration of a loop. Each iteration does **exactly one ticket**, then stops.

## Goal of the whole loop

Produce, in the same run, two outputs:

1. **Grouped output — must stay byte-for-byte equivalent in content to today's output**:
   `estacoes.parquet` + `log.parquet` (Log column factorized into integer ids), and the per-source
   `telecom.parquet`, `smp.parquet`.
2. **Full output — new**: `estacoes_full.parquet` (plus per-source `telecom_full.parquet`,
   `smp_full.parquet`) where Mosaico rows are **not** collapsed by `Mosaico.aggregate`
   (the `groupby` in `extracao/datasources/mosaico.py`, called from `smp.py` and `telecom.py`).
   The `Log` column stays **inline** in the same dataframe as a JSON string (after `merge_dicts`),
   it is **not** split into a separate `log.parquet`. Omit `Multiplicidade` from the full
   consolidated and per-source outputs; retain it unchanged in the grouped outputs.

## Iteration protocol

1. Read `ralph/prd.json` and `ralph/progress.txt` (especially the "Codebase patterns" section).
2. Pick the **first** ticket (lowest `priority`) with `"passes": false` whose `dependsOn` are all `passes: true`.
3. Implement only that ticket. Keep changes surgical.
4. Run the ticket's `verify` commands. All must pass (except the known pre-existing failures listed below).
5. If it passes: set `"passes": true` in `prd.json`, append a short entry to `progress.txt`
   (what changed, files, gotchas learned), stage only files belonging to the ticket, and commit
   with message `<type>(<scope>): <ticket id> <title>` and trailer
   `Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>`.
6. If it fails and you cannot fix it this iteration: leave `passes: false`, write the blocker in the
   ticket `notes` and in `progress.txt`, and stop.
7. If every ticket has `passes: true`, output `<promise>COMPLETE</promise>`.

## Repository rules (must follow)

- `extracao/**/*.py` modules are the **source of truth** even though they carry
  "AUTOGENERATED! DO NOT EDIT" headers. Notebooks in `nbs/` only mirror them for docs; they are
  synced in a dedicated ticket (FULL-14), not in every ticket.
- Python: always use `.venv/bin/python`. Tests use stdlib unittest (pytest is not installed):
  `.venv/bin/python -m unittest discover -s tests`
- Pandas 3 enables Copy-on-Write by default. `extracao/__init__.py` enables it only for earlier
  pandas versions; do not add per-module option assignments. `Base.register_log` mutates
  `df["Log"]` in place — never share one DataFrame object between the grouped and full pipelines.
- Data caches live in `extracao/datasources/arquivos/saida/` (gitignored). Raw caches
  (`telecom_raw.parquet` ≈5.45M rows, `smp_raw.parquet` ≈2.38M rows, `srd_raw`, `stel_raw`,
  `radcom_raw`, `aero_raw`) are present, so everything can run offline with `read_cache=True`.
  No MongoDB / SQL Server access is assumed.
- Never commit parquet files or baselines (`*.parquet` is gitignored).
